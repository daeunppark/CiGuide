Definitions and assumptions

All lengths are in bytes: n = plaintext length; a = associated-data length; p = PKCS#7 padding (1–16 bytes for CBC); v = IV/nonce length; t = authentication-tag length; s = timestamp length. CBC IVs are 16 bytes; full HMAC-SHA256 tags are 32 bytes.

Storage counts the ciphertext and listed metadata stored with it. It excludes keys, associated data, protocol headers and replay state. Time bounds assume linear processing and fixed key/tag/timestamp sizes. If CBC configurations authenticate variable-length associated data, their bounds also become O(n + a). Parallelizability is not a measured speed ranking.

Timestamp freshness checking alone does not prevent all duplicate replays or guarantee ordering. Decrypted data must not be released before authentication succeeds. Message-length requirements describe the algorithms; library APIs may impose additional restrictions.
